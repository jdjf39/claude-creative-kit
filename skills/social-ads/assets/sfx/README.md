# Sound effects go here

The sound files are not included in this kit because their licence does not clearly allow passing them on.
Put your own WAV files (48 kHz stereo) in this folder using these names, and the scripts will pick them up:

key, typing, paper_turn, paper_crinkle, domino_rattle, chime_up, chime_soft, sparkle_rise, whoosh,
whoosh_short, swipe, swish, swish_thud, whoosh_thud, pop, blip, click, swell, fly_through, logo_sting
(social-ads also uses: notify, stamp, buzz)

Free places to get them: Mixkit, Pixabay, Freesound (check each licence). Ask Claude:
"find me a free whoosh sound effect and save it as whoosh.wav in the sfx folder".
